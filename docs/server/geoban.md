# 地区封禁
MineBlock 致力于让来自于世界上任何地方的玩家都能尽情享受游戏，但有时，集中于特定地区的玩家会对服务器进行大规模的恶意行为，导致我们不得不采取措施保护其他玩家。

本页面阐述了我们如何施加地区封禁，以及如果您正在使用受影响的 IP 地址，如何与我们取得联系以游玩 MineBlock。

## 封禁条件
一旦我们检测到某个地区所属的 IP 具有如下特征，我们就会对这个地区施加封禁：

- 单个地区内超过 80% 的 IP 被识别为代理 IP
- 在连续的 24 小时内，单个地区内超过 80% 的玩家被处罚
- 在连续的 24 小时内，单个地区内存在假人攻击（采用自动化程序批量控制账号恶意连接服务器的行为）

每一个地区封禁均会通过管理员的审核并手动施加，因此，不接受针对特定地区解除封禁的请求。

## 当前封禁的国家/地区
以下是我们已施加地区封禁的名单，如果您所在的位置被列入名单，请查看“如何豁免地区封禁”部分了解如何联系我们为您单独解除封禁。

- 澳大利亚（Australia）
- 英国（United Kingdom）
- 荷兰（The Netherlands）
- 立陶宛（Lithuania）

## 如何豁免地区封禁
如果您所在的位置被列入地区封禁名单，请将以下信息发送至我们的邮箱 [service@mineblock.cc](mailto:service@mineblock.cc) 或加入我们的 [Discord 服务器](https://discord.gg/BfYVpqVmts)寻求管理员的帮助：

- Minecraft 账户 UUID（**不是玩家名**，可以在 [namemc.com](https://namemc.com) 找到您的 UUID）
- IP 地址（可以在 [ifconfig.me](https://ifconfig.me) 找到您的 IP 地址）
