# 会员等级

会员等级是 MineBlock 的重要组成部分，会员等级能够体现一名玩家为 MineBlock 提供的支持或是其在 MineBlock 的地位。

## 可购买的会员等级

在 MineBlock，有五种可购买的会员等级，分别是 VIP、VIP+、MVP、MVP+ 和 MVP++。

不同的会员等级具有不同的特权，这些特权能够提升你在 MineBlock 的游戏体验，包括独特的聊天文字颜色、欢迎信息、特效等不影响游戏平衡的特权。

## 特殊会员等级

特殊会员等级授予给对 MineBlock 具有特殊意义的玩家，这类会员等级具有特殊的获取条件，并且具有与可购买的会员等级完全不同的特权。

特殊会员等级的获取均需要向管理员团队申请并经过确认，MineBlock 的所有特殊会员等级及其获取条件在下文列出。

* 主播/视频制作者
  * 前缀：\[UP\]
  * 获取条件：在哔哩哔哩、虎牙、斗鱼等视频/直播平台拥有 3000 个粉丝
  * 特权：
    * MVP++ 的所有特权
    * 允许向聊天发送第三方链接（仅可用于宣传自己的社交媒体）
* 建筑师
  * 前缀：\[建筑师\]
  * 获取条件：为 MineBlock 贡献 1 张地图
  * 特权：
    * MVP++ 的所有特权

## 管理团队会员等级

拥有管理团队会员等级的玩家在 MineBlock 具有一定的管理权限，能够在一定程度上管理 MineBlock 服务器内的事务。

* 志愿者
  * 前缀：\[志愿者\]
  * 获取条件：
    1. 过去 1 个月内没有有效的处罚记录，且
    2. 具有 VIP 及以上会员等级，且
    3. 向管理员团队提出申请
  * 特权：
    * 允许对玩家进行有限时长的处罚
    * 允许绕过普通玩家的通常限制
* 协管
  * 前缀：\[协管\]
  * 获取条件：
    1. 担任志愿者达到 1 个月，且
    2. 向管理员团队提出提拔申请
  * 特权：
    * 允许对玩家进行更久的处罚
    * 允许绕过普通玩家的通常限制
* 管理员
  * 前缀：\[管理员\]
  * 获取条件：成为 MineBlock 的成员
  * 特权：所有权限
* 服主
  * 前缀：\[服主\]
  * 特权：所有权限
  * 出于显而易见的原因，此会员等级仅授予 AmbilightLast
