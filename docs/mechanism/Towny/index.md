# Towny 城镇

Towny，即城镇，是玩家保护自己领地的重要组成部分。MineBlock 使用 Towny 保护并管理玩家们的每一座建筑。

Towny 的最大优势之一在于，没有传统领地插件的木锄头，也没有奇葩玩家占领形状奇特的区域来戏弄其他玩家。玩家可以单打独斗，也可以结盟组成复杂的团队。玩家可以自行占领区域、自定义游戏内的防御措施、进行击杀、重生、传送等等，所有这些都取决于玩家如何打造他们的城镇。

适用服务器：**纯净生存**

## 城镇介绍

每个“城镇”都有一位“市长”，而每个“国家”则有一位“国王”。他们各自都有自己的“助手”来协助管理各自的“居民”。玩家可以从城镇购买土地，还可以选择缴纳市长设定的每日税款。如果玩家愿意，还可以允许外来的朋友在他的土地上建造，即使他所属城镇的其他居民无法建造。

## 城镇如何保护玩家们的领地

保护机制的基础是基于 Minecraft 世界按区块划分的方式。对于对区块不了解的玩家，这里有一个简单的解释：Minecraft 的每个世界都可以被划分成 16x16x384 个方块的区域，这块区域即为“区块”，一个世界就是由无数个（但实际上是有上限的）区块组成的。384 代表从基岩地面到天空云层的高度，但通常来说，区块没有高度，或者说区块忽略高度，只认长 16 宽 16 围成的正方形区域，并通过无上限的高度组成一个长方体区域。城镇保护机制保护的就是一个个区块。因此，认领一个城镇区块（一个网格正方形）后，该区域即可遵循所在城镇或地块所有者的权限。

## 城镇的运作方式

每个城镇最多可以认领一定数量的城镇区块，认领数量上限与城镇的规模正相关，城镇的规模则与居民数量正相关。居民本身能够认领的城镇区块数量没有上限，但每日税收会消耗他们的经济。这笔钱会直接存入城镇的银行账户，只有市长才能提取，除非该城镇隶属于某个国家。任何隶属于某个国家的城镇可能还需要向该国支付每日维护费。

换句话说，一个城镇的居民越多，城镇规模越大，城镇等级越高，能够认领的区块越多，每日需要缴纳的维护费也越多。

MineBlock 服务器通常在北京时间每日 12 时定时收取城镇维护费，城镇银行中没有足额维护费的城镇将会被删除（但不会移除城镇内的建筑）。设立维护费的初衷是防止无序扩张，影响其他玩家的体验，维护费也能调整服务器的总体经济，维持游戏平衡。

## 城镇战争

土地之神（管理员）可以启动和结束战争模式。战争期间，大多数命令将被冻结，以便专注于战争事件。战争期间，城镇权限将被忽略，任何隶属于某个国家的城镇都将完全暴露在其他国家的居民面前，没有任何保护。此外，每个单元（即城镇区块）都有一定的生命值。当非盟友玩家进入城镇街区时，该街区的生命值会下降。城镇居民必须一边攻击其他玩家，一边将非盟友玩家驱逐出去。当生命值降至零时，城镇将失去对该街区的所有权。城镇战争的目标是占领其他城镇的家园区块，也就是城镇居民的重生点。
